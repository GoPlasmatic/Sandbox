# ISO 20022 Sample Generator

Generate CBPR+ compliant ISO 20022 XML messages for testing and development. Select a message type and scenario to create valid XML that conforms to ISO 20022 schemas and CBPR+ guidelines.

<div class="reframe-playground" data-tab="generate"></div>

## How It Works

Each message type (pacs.008, pain.001, etc.) has predefined scenarios representing real-world use cases. The generation process:

1. Retrieves the appropriate scenario configuration
2. Constructs the XML message structure according to ISO 20022 schemas
3. Populates fields with realistic test data following CBPR+ requirements
4. Applies business rules and conditional logic
5. Validates the complete message against XSD schemas
6. Returns a well-formed, valid ISO 20022 XML message

## Supported Message Types

### Payment Messages (pacs)
- **pacs.002** - FIToFI Payment Status Report
- **pacs.003** - FIToFI Customer Direct Debit
- **pacs.008** - FIToFI Customer Credit Transfer
- **pacs.009** - Financial Institution Credit Transfer

### Payment Initiation (pain)
- **pain.001** - Customer Credit Transfer Initiation
- **pain.008** - Customer Direct Debit Initiation

### Cash Management (camt)
- **camt.025** - Receipt
- **camt.029** - Resolution of Investigation
- **camt.052** - Bank to Customer Account Report
- **camt.053** - Bank to Customer Statement
- **camt.054** - Bank to Customer Debit/Credit Notification
- **camt.056** - FIToFI Payment Cancellation Request
- **camt.057** - Notification to Account Owner
- **camt.060** - Account Reporting Request
