# ISO 20022 Validator

Validate ISO 20022 XML messages against XSD schemas, business rules, and CBPR+ compliance requirements. The validator also provides canonical JSON representation for easy integration and processing.

<div class="reframe-playground" data-tab="validate"></div>

## How It Works

The validation process follows these steps:

1. Parses the input ISO 20022 XML message
2. Validates the message structure against ISO 20022 XSD schemas
3. Applies CBPR+ business validation rules
4. Checks mandatory fields and data types
5. Validates cross-field dependencies and business logic
6. Generates canonical JSON representation if requested
7. Returns detailed validation results with specific error messages

## Features

- **Schema Validation**: Validates messages against official ISO 20022 XSD schemas
- **Business Rule Validation**: Applies CBPR+ specific business rules and constraints
- **Canonical JSON Conversion**: Converts validated messages to a standardized JSON format
- **Detailed Error Reporting**: Provides specific error messages with field paths
- **Multiple Message Types**: Supports all major ISO 20022 message types (pacs, pain, camt)

## API Reference

### Endpoint
```
POST /api/validate
```

### Request Body
```json
{
  "message": "<ISO20022 XML message>",
  "options": {
    "canonical": true,
    "business_validation": true,
    "fail_fast": false
  }
}
```

### Response Format
```json
{
  "success": true,
  "message_type": "pacs.008.001.08",
  "errors": [
    {
      "error_type": "parser_error",
      "code": "INVALID_FORMAT",
      "message": "Error description",
      "field": "field.name",
      "location": "XPath or location in message",
      "details": { ... }
    }
  ],
  "canonical_json": { ... }
}
```
